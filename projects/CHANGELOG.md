# Changelog

`skyportal-py` and `skyportal-py-models` are versioned and released together,
by date: `YYYY.MM.MICRO`. Releases up to 0.4.0 used SemVer.

## 0.4.0 (2026-09-22)

### Features

#### Develop the clients in the SkyPortal repository

The Python client and the pydantic models it shares with the server live in
`projects/` and are released from here. The standalone `skyportal-py`
repository, last released as 0.3.3, is superseded.
