# Changelog

The app and the Python packages under `projects/` share one version, released
together and tagged together. Releases are dated: `YYYY.MM.MICRO`, where the
micro counts releases within the month.

## 1.4.0

The last release before the switch to dated versions. Changes up to this point
are in the git history; the packages under `projects/` were versioned
separately, up to 0.4.0.
